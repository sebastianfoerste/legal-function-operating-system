# Review-workspace programme

The legal function workspace renders deterministic Lists for requests, contracts, obligations, entities and facts. Items include source references, evidence, owners, deadlines, dependencies and resolution gates.

Workflow definitions support draft comparison, dry-run inspection and activation after a named reviewer approval. The self-contained HTML portal includes local search, approved resources, citation-only answers and explicit abstention. It has no external dependency or send route.

Run `make test` and compare two generated output directories with `diff -ru`. The example data is synthetic and all external action flags remain false.

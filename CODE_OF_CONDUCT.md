# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone who takes part in issues, pull requests and discussions is expected to follow it.

## In short

- Be respectful and assume good faith. Critique rules, thresholds and code, not people.
- No harassment, insults, personal attacks or publishing other people's private information.
- Synthetic data only. Never post real legal requests, client or employer matters, contracts or personal data, not even redacted, in an issue, a pull request or a fixture.
- Nothing in this project is legal advice. Discuss how a rule behaves, not someone's live matter.

## Enforcement

Report unacceptable behaviour privately through the maintainer's GitHub profile contact details. The maintainer will review every report, keep the reporter's identity confidential, and may remove content or block participants who break this code, following the enforcement guidelines of the Contributor Covenant.
